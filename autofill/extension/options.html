Resume Autofill — Settings

Everything here is stored locally in the browser (chrome.storage.local). Nothing is uploaded anywhere except to the bridge URL you set below, which is your own machine by default.

Profile

Pretty-printed JSON. This is the source of truth for every deterministic fill, and it is also what gets sent to the AI bridge as context. It must be valid JSON — Save refuses anything that does not parse.

AI bridge URL

The local helper service that answers free-text questions. Default: http://localhost:3111. If it is not running, the extension silently falls back to deterministic filling.

Extra model instructions

Free text appended to the AI prompt. Use it for standing preferences, e.g. "Answer salary questions with 'Negotiable'." or "Never write more than 3 sentences in a cover-letter box."

Learned answers

Every question you answered on the "questions need your answer" page. These are matched BEFORE your profile and before the AI, because you typed them yourself. The question text is normalised, so one answer covers the same question on every job site that asks it. Forgetting one means you will be asked it again the next time it comes up.
